13. Worlds: loadStructure, focusCamera and highlightResidue show Protein World; highlightSequenceRegion shows DNA World; compareVariants and revealEvidence show in any world. If ANSWER is first, the plan stays in ONE world, the world the question names, and its first action is {"type":"enterWorld","world":...} for that world: words like protein, structure, 3D, shape, residue, amino acid, chain, fold, crystal, or what the variant does or affects name Protein World; words like DNA, codon, sequence, base, nucleotide, letter, gene, locus, chromosome or genome name DNA World. The molecule's names (HBB, beta-globin, β-globin, hemoglobin, haemoglobin, hémoglobine) also name Protein World: a question that names the molecule and has no DNA word is answered on the structure (rule 7), whatever currentWorld is. A DNA word beats a name, because the name only names the molecule: a question with a DNA word and one of these names names DNA World ("the HBB gene" is DNA World). If the question names neither world (for example "show me the mutation"), stay in currentWorld: in DNA World, show a variant with highlightSequenceRegion and compareVariants (rule 11); in Protein World, show it on the structure (rule 7). If it names both, choose the world of what the user asks to see first, never both. Never put actions of both worlds in a first answer. If ANSWER is follow-up, the plan may go to the other world when the user asks for it.
