# Diagrams

Four hand-written SVG diagrams of the code as it is at the Phase 12 build of record (`docs/reviews/phase-12-bor.md`). Each box names a module, file, function or data source, and each arrow is a call or a data flow in that code. Paths in helix-research are written from that repository's root; paths in helix-app from this repository's root. The paragraphs below give the mapping a reviewer can check.

## data-path.svg

The top row is the nine public sources, named by the `source` id each manifest records (`data/curated/*/manifest.json` in helix-research); the four with a teal border are `DYNAMIC_SOURCES` in `packages/scientific-core/src/slice/dynamic-steps.ts`. In helix-research: "data-adapters" is `packages/data-adapters/src` (`HttpClient` in `http/client.ts`, one file per source in `adapters/`); "acquireSlice()" is `packages/scientific-core/src/slice/acquire.ts`; "buildGene()" is `scripts/data-preparation/build-gene.ts` and `lib/build-gene.ts` with its three modes; "RecordCache snapshot" is `packages/data-adapters/src/cache.ts` writing `.cache/helix-raw`; "Gene specification" is `data/specs/<gene>.json` read by `loadGeneSpec()` in `slice/spec.ts`; "Recorded fixtures" is `data/fixtures/<gene>/`, written by `lib/fixture-recorder.ts` after `packages/data-adapters/src/redaction.ts`; "buildSlice()" and "buildManifest()" are `slice/build.ts` and `slice/manifest.ts`, the latter hashing with `sha256Hex()` in `packages/data-adapters/src/hash.ts`; "data/curated/<gene>/" is the five committed sets; "Rebuild checks" is `scripts/data-preparation/compare-builds.ts` and `trace-records.ts`. In helix-app: "Research pin" is `package.json` (`helix.researchCommit`) and `scripts/check-research-pin.mjs`; "copy-data.mjs" is `apps/web/scripts/copy-data.mjs` (`npm run prepare-data`); "public/data/<id>/" is its output with `index.json`; "release-build.mjs" is `scripts/release-build.mjs`; "loadCuratedBundle()" and "bundleFromMemory()" are in `apps/web/src/data.ts` (both through `assembleBundle()`); "retrieveDynamic()" and "Web Worker" are `apps/web/src/dynamic/client.ts` and `worker.ts`; "AppController.create()" is in `apps/web/src/controller.ts`. The "not curated" label is `dynamicCaption()` in `apps/web/src/phase6.tsx`.

## ai-path.svg

"Visitor's question" is the `AskBar` component of `packages/design-system`; "AppController.ask()" is in `apps/web/src/controller.ts`. The context column is `buildHbbContext()` (helix-research `packages/ai-planning/src/context.ts`), `restrictToBuild()` (`packages/ai-director/src/providers.ts`), and `Director.contextFor()` with `withSelectionFacts()` (`packages/ai-director/src/director.ts`; helix-research `packages/ai-planning/src/contextual.ts`). The Director column is `Director.handle()` in `packages/ai-director/src/director.ts`, in its order: `deterministicPlan()` (helix-research `ai-planning/src/fallback.ts`, which calls `routeQuestion()` in `routing.ts`), `splitRoute()`, the `ProviderRegistry` built by `createProviderRegistry()` (helix-research `providers/registry.ts`; helix-app `providers.ts`), `OllamaProvider.plan()` (`providers/ollama.ts`, prompt from `prompt.ts`), `validatePlan()` (`validate.ts`, with the schemas of `schema.ts`), `retrievedEchoes()` and `screenClaims()` (`director.ts`, `claim-screen.ts`), `splitAccepts()`, and `screenPlanFollowUps()` (`followups.ts`). "Rule-based plan" is the Director's `deterministic(...)` result, whose `source` is `deterministic`. "Local Ollama server" is outside the app; on the desktop the provider reaches it through the shell's fetch (see desktop-shell.svg). The scene column is `SceneActionInterpreter` (`packages/scene-engine/src/interpreter.ts`), `ACTION_REGISTRY` (`packages/ai-actions/src/registry.ts`), `TargetResolver`, `SequenceResolver` and `DomainResolver` (`scene-engine/src/resolver.ts`, `sequence-actions.ts`, `domains.ts`), `WorldExecutors` (`apps/web/src/stage.ts`, with `molstar/scene.ts`, `dna/DnaWorld.tsx`, `ui/PathwayWorld.tsx`), `SessionStore` (`scene-engine/src/session.ts`), `composeExplanation()` (`apps/web/src/evidence.ts`) and `nextQuestions()` (`packages/ai-director/src/next-questions.ts`, which calls `filterFollowUps()`).
