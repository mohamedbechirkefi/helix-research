Not run: `cargo audit` on the Tauri experiment's `Cargo.lock` (the tool is not installed; installing it is a free user-space step listed in the plan, P11.3.2).

No entry lacks a licence field. "Non-dev" in a lockfile means "installed for a production install", not "in the browser bundle": the bundle is a subset (P11.3.3 derives the notices from the bundle, not the lockfile).

Version pinning: no `^` or `~` range in any `package.json` of either repository (grep over the root, `apps/*` and `packages/*` manifests returned nothing).

### 3. Read-only code inspection (no execution)

- `apps/web/index.html` and the Vite config carry no Content-Security-Policy (grep for `content-security` and `csp`: no match). The Tauri experiment's `tauri.conf.json` does carry one, and its capability file allows HTTP to `http://localhost:11434/*` only.
- No `dangerouslySetInnerHTML`, `innerHTML`, `eval(` or `new Function` in `apps/web/src` (grep: no match).
- No in-browser model engine is wired into the shipped build: `aiStatus()` in `apps/web/src/controller.ts` states "no in-browser model engine is included in this build"; `createProviderRegistry` adds `WebLLMProvider` only when an engine factory is passed, and the app passes none.
- No WebGL-unavailable fallback path was found in `apps/web/src` (grep for `webgl`: only the context counter in `main.tsx` and render targets).
- Installed browsers on the development Mac: Google Chrome and Safari 18.3 (`CFBundleShortVersionString`); no Firefox.

## Failures

One stray command: an attempt to read Safari's version by calling its binary with `--version` did not return within the tool timeout and was stopped by this session (its own task); no Safari process remained (`pgrep` empty afterwards). The version was then read from the bundle's Info.plist.

## Limits

Single read of each advisory database at one time; advisories change. The licence tally trusts each package's declared `license` field, which is not the same as reading its licence file (P11.3.3 does that for the bundled packages).

## Interpretation

Inputs for the plan only: one known high advisory outside the browser bundle, owed an upgrade; a licence mix that the third-party notices must cover (MIT, ISC, Apache-2.0, BSD, 0BSD, Python-2.0, and MPL-2.0 in build tooling); no CSP on the web build; no in-browser model in the shipped build.
