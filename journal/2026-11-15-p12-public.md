## Findings

- **Cloudflare's own types broke two section 8 items.** It sends `.cif` as `chemical/x-cif`, which is not on its compression list, so the four structure files (0.47 to 4.2 MB) went out uncompressed. The HBB file is fetched at rest, which put the bytes at rest over the budget (2.73 MB). It sent the page without a charset; the page declares `<meta charset="utf-8">` and is ASCII, so no visitor saw a difference. Fix: `_headers` now names the Content-Type of `/`, `/index.html` (`text/html; charset=utf-8`) and of each `.cif` by exact path (`text/plain; charset=utf-8`, allowed by item 4). Cloudflare applied both, and compression followed the type.
- **The bytes at rest on the real host are 1,985 kB against the 2,000 kB budget**, a margin of about 14 kB.
- **S21's offline guard blocked the served host itself.** It aborted every request to a host other than `localhost` and `127.0.0.1`, so its question run could not open a public URL. It now also allows the host of `HELIX_BASE`. No app change.
- **The text differences against the build of record are all expected on a public host:** run timestamps, the local model's lines (a public page never reaches a local model), and one loading line captured in passing.
- **S6 and S19's development halves do not apply to a public URL.** A public host serves the page as platform "web": no model request is made. S19's web half runs on its own local server over `dist`, not on the URL. This is the design recorded in docs/hosting-cloudflare.md, now seen on the real host.
- **The S6 run overwrote a committed screenshot** (`docs/reviews/phase-4-shots/fallback-reference.jpg`); it was restored from git.

## Uncertainty

The session's connection was slow and unstable that evening: a GitHub outage of several minutes earlier, and the fetch timings above. The two S21 accessibility stops are 30 s navigation timeouts at different steps; the same run passed in full on the first deploy, whose app files are identical (only `_headers` changed). It was not rerun to completion on the redeploy. One machine, one network, one region of Cloudflare's edge.

## Interpretation

The hypothesis holds on the redeploy: every applicable section 8 requirement passes on the real URL, and the bytes at rest are within the budget, narrowly. S21's accessibility half has a full pass only on the first deploy. The demo is public.
